**Judging Criteria**

**HACK4HEALTH 2026**

**Technical Track Submission Template**

**Maximum 4 pages (excluding appendix)**

**1. Team Information**

* Team Name
* Institution(s)
* Members (1–5)
* Contact Person

**2. Executive Summary (200 words)**

Describe your solution in plain English.

**3. Problem Understanding**

Describe

* Current clinic workflow
* Pain points
* Root causes
* Why the problem matters

**4. Proposed AI Solution**

Explain

* AI used
* Workflow
* User journey
* How clinicians/patients interact with it

Include diagrams if helpful.

**5. Technical Architecture**

Describe

* LLM
* AI models
* APIs
* Databases
* Azure services
* Integration with Clinic Assist/NEHR (conceptually)

**6. Operational Impact**

Quantify expected improvements.

Examples

* Waiting time
* Administrative workload
* Vaccination uptake
* Revenue
* Safety

**7. Feasibility**

Explain

* Why it can realistically be implemented with Copilot Studio

Resources required

Timeline

Dependencies

**8. Governance & Safety**

Address

* PDPA
* Human oversight
* AI hallucination mitigation
* Audit trail
* Security

**9. Scalability**

Explain how it can expand across

* Parkway Shenton
* IHH

Optional
